# 量子猜拳 (Quantum Duel)

量子猜拳是一款基於 Python 的終端機策略對戰遊戲。玩家與 AI 進行回合制決鬥，透過斬擊、格擋與蓄能的抉擇來擊敗對手。

## 快速開始

### 系統需求
- Python 3.6 或以上版本

### 執行步驟
1. 複製或下載本專案。
2. 開啟終端機並切換至專案目錄。
3. 執行以下指令啟動遊戲：
   ```bash
   python "Quantum Duel.py"
   ```

## 遊戲規則與機制

雙方初始皆擁有 12 點生命值 (HP)。每回合雙方必須同時選擇以下其中一項行動：

- **斬擊 (a)**：發動普通斬擊造成 2 點傷害；若處於蓄能狀態，則發動「量子斬」造成 4 點傷害，並消耗蓄能狀態。
- **格擋 (b)**：減少本回合受到的斬擊傷害 2 點；若對手選擇蓄能，則可看穿其破綻並對其造成 1 點傷害。
- **蓄能 (c)**：進入蓄能狀態，使下一次斬擊強化為量子斬。
- **離開 (q)**：結束遊戲。

### 行動判定表 (Resolve Matrix)

| 玩家行動 | AI 行動 | 結算結果 |
| :--- | :--- | :--- |
| **斬擊 (a)** | **斬擊 (a)** | 雙方互相造成傷害 (依是否蓄能決定為 2 或 4)。雙方蓄能狀態解除。 |
| **斬擊 (a)** | **格擋 (b)** | 玩家對 AI 造成傷害 (依是否蓄能減免 2，即 0 或 2)。玩家蓄能狀態解除。 |
| **斬擊 (a)** | **蓄能 (c)** | 玩家對 AI 造成傷害 (2 或 4)。AI 進入蓄能狀態。玩家蓄能狀態解除。 |
| **格擋 (b)** | **斬擊 (a)** | AI 對玩家造成傷害 (依是否蓄能減免 2，即 0 或 2)。AI 蓄能狀態解除。 |
| **格擋 (b)** | **格擋 (b)** | 無事發生。 |
| **格擋 (b)** | **蓄能 (c)** | 玩家對 AI 造成 1 點傷害。AI 進入蓄能狀態。 |
| **蓄能 (c)** | **斬擊 (a)** | AI 對玩家造成傷害 (2 或 4)。玩家進入蓄能狀態。AI 蓄能狀態解除。 |
| **蓄能 (c)** | **格擋 (b)** | AI 對玩家造成 1 點傷害。玩家進入蓄能狀態。 |
| **蓄能 (c)** | **蓄能 (c)** | 雙方皆進入蓄能狀態，不造成傷害。 |

## AI 策略邏輯

遊戲中的 AI 會根據當前局勢調整其行動權重，並非完全隨機：

- **一般狀態**：斬擊 (45%)、格擋 (25%)、蓄能 (30%)。
- **AI 處於蓄能狀態**：傾向發動攻擊，斬擊 (65%)、格擋 (25%)、蓄能 (10%)。
- **玩家處於蓄能狀態**：傾向防守，斬擊 (30%)、格擋 (50%)、蓄能 (20%)。
- **AI 生命值危急 (<= 4 HP)**：傾向速戰速決或防守，斬擊 (55%)、格擋 (30%)、蓄能 (15%)。

## 程式碼結構

本專案主要由單一檔案 [Quantum Duel.py](file:///d:/Code/Quantum-Duel/Quantum%20Duel.py) 組成。

- **資料結構**
  - [Fighter](file:///d:/Code/Quantum-Duel/Quantum%20Duel.py#L19-L24)：定義角色狀態，包含名稱、生命值 (hp) 與是否蓄能 (charged)。
- **核心函數**
  - [resolve](file:///d:/Code/Quantum-Duel/Quantum%20Duel.py#L26-L64)：計算並結算每回合雙方的行動，更新角色狀態並返回戰鬥日誌。
  - [ai_move](file:///d:/Code/Quantum-Duel/Quantum%20Duel.py#L67-L78)：根據當前局勢動態計算權重，決定 AI 的下一步行動。
  - [main](file:///d:/Code/Quantum-Duel/Quantum%20Duel.py#L98-L134)：遊戲主迴圈，負責初始化、讀取玩家輸入、呼叫結算與判定勝負。
