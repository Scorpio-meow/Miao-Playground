# Quantum Duel｜量子猜拳

一個用 Python 製作的終端機小遊戲。

在這場不太科學、但很有氣勢的決鬥裡，你要和 AI 進行回合制對戰：斬擊、格擋、蓄能，抓準節奏打出致命的 **量子斬**。

## 遊戲特色

- 純 Python，無需額外套件
- 終端機即可遊玩，開檔就能開打
- 簡單規則，但有一點心理戰
- AI 會根據局勢調整出招傾向
- 文字敘述帶一點幽默感，輸贏都不無聊

## 遊戲規則

- 你和 AI 初始各有 **12 HP**
- 每回合可以選擇以下行動：
  - `a` = **斬擊**：造成穩定傷害
  - `b` = **格擋**：降低對手斬擊傷害
  - `c` = **蓄能**：為下一次斬擊強化
  - `q` = **離開遊戲**

### 行動效果

#### 斬擊
- 一般狀態下造成 **2 點傷害**
- 若前一回合已蓄能，則升級為 **量子斬**，造成 **4 點傷害**

#### 格擋
- 若對手本回合使用斬擊，可使受到的傷害 **減少 2 點**
- 如果成功抓到對手蓄能空檔，還能額外造成 **1 點傷害**

#### 蓄能
- 讓下一次斬擊升級為 **量子斬**
- 但若被對手趁機針對，可能會先吃到傷害

## AI 行為

AI 不是完全亂出招，會依照戰況調整策略，例如：

- AI 已蓄能時，更傾向直接進攻
- 玩家已蓄能時，AI 更傾向格擋
- AI 血量偏低時，會提高攻擊機率

簡單說，它不是天才，但也不是木頭。

## 執行方式

請先確認你的電腦已安裝 Python 3。

在專案資料夾中執行：

```bash
python "Quantum Duel.py"
```

如果你的環境使用 `python3`，也可以改用：

```bash
python3 "Quantum Duel.py"
```

## 操作說明

進入遊戲後，畫面會顯示雙方 HP 與狀態。

輸入以下按鍵後按 Enter：

- `a`：斬擊
- `b`：格擋
- `c`：蓄能
- `q`：離開
