# 星塵迷宮 (Stardust Labyrinth)

星塵迷宮是一款基於 Python 終端機開發的純文字迷宮冒險小遊戲。玩家需要在躲避幽靈追擊的同時，收集迷宮中散落的所有星塵。

## 快速開始

### 系統需求

- Python 3.7 或更高版本

### 執行遊戲

此遊戲不需要安裝額外的第三方套件，直接使用 Python 內建標準庫即可運行。

請在終端機中執行以下指令：

```bash
python "Stardust Labyrinth.py"
```

## 遊戲規則

- **玩家 (@)**：您控制的角色。
- **星塵 (*)**：散落在迷宮中的能量，收集所有星塵即可獲得勝利。
- **幽靈 (G)**：在迷宮中游蕩的敵人。幽靈會在每個回合朝最靠近您的方向移動一步。一旦被幽靈碰觸，遊戲即結束。
- **牆壁 (#)**：無法穿過的障礙物。

### 控制方式

在遊戲提示輸入時，輸入以下字元並按下 Enter 鍵：

- `w`：向上移動
- `a`：向左移動
- `s`：向下移動
- `d`：向右移動
- `q`：退出遊戲

## 自訂配置

您可以透過修改 [Stardust Labyrinth.py](file:///d:/Code/Stardust-Labyrinth/Stardust%20Labyrinth.py) 檔案中的 `RAW_MAP` 陣列來設計您自己的迷宮。

### 預設地圖

預設的迷宮地圖定義如下：

```python
RAW_MAP = [
    '###########',
    '#@..#....*#',
    '#.#.#.##..#',
    '#.#...#...#',
    '#.###.#.#.#',
    '#...#...#.#',
    '#.#.###.#.#',
    '#.#...#...#',
    '#..##.#.#G#',
    '#*....#..*#',
    '###########',
]
```

### 地圖編輯規範

- `#`：牆壁
- `.`：通道
- `@`：玩家起點 (只能有一個)
- `G`：幽靈起點 (只能有一個)
- `*`：星塵 (可放置多個)

## 程式碼架構

本專案結構極為簡潔，所有核心邏輯皆封裝於單一檔案中：

- [Stardust Labyrinth.py](file:///d:/Code/Stardust-Labyrinth/Stardust%20Labyrinth.py) ：主遊戲腳本。

### 核心類別與函式

- **Game**：核心遊戲狀態管理類別。
  - `from_map(raw)`：從原始文字地圖初始化遊戲狀態。
  - `draw()`：在終端機中繪製目前的迷宮與狀態。
  - `step_player(move)`：更新玩家位置，並處理星塵收集。
  - `step_ghost()`：根據玩家當前位置，計算並移動幽靈 (採用曼哈頓距離最短路徑)。
  - `player_caught()`：判定幽靈是否追上玩家。
- **main()**：程式入口點，負責遊戲主迴圈、輸入處理以及勝負判斷。
