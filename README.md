# Stardust-Labyrinth

一個使用 Python 製作的終端機迷宮小遊戲。你將扮演探險者 `@`，在幽靈 `G` 追上你之前，蒐集地圖中的所有星塵 `*`。

## 遊戲特色

- 純 Python 撰寫，無需額外安裝第三方套件
- 終端機介面，開啟就能玩
- 簡單直覺的 `WASD` 操作
- 幽靈會主動追蹤玩家位置，增加緊張感

## 遊戲目標

在迷宮中移動並收集全部星塵，若被幽靈碰到則遊戲失敗。

## 符號說明

| 符號 | 意義 |
| --- | --- |
| `@` | 玩家 |
| `G` | 幽靈 |
| `*` | 星塵 |
| `#` | 牆壁 |
| `.` | 可通行道路 |

## 操作方式

| 按鍵 | 功能 |
| --- | --- |
| `W` | 向上移動 |
| `A` | 向左移動 |
| `S` | 向下移動 |
| `D` | 向右移動 |
| `Q` | 離開遊戲 |

輸入不合法按鍵時，遊戲會提示重新輸入。

## 執行方式

請先確認系統已安裝 Python 3。

在專案目錄中執行：

`python3 "Stardust Labyrinth.py"`

## 遊戲規則

1. 玩家每回合可移動一步。
2. 若撞到牆壁，該回合不會成功移動。
3. 玩家走到星塵位置時，會自動拾取星塵。
4. 玩家行動後，幽靈會朝玩家靠近一步。
5. 收集完所有星塵即獲勝。
6. 玩家與幽靈位於同一格時即失敗。

## 程式設計重點

`Stardust Labyrinth.py` 主要包含：

- `RAW_MAP`：定義迷宮地圖
- `DIRS`：定義玩家移動方向
- `Game` 類別：負責遊戲狀態、畫面繪製、玩家與幽靈移動邏輯
- `main()`：遊戲主迴圈與輸入處理
